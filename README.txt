HOW TO UPLOAD
1. Extract this ZIP file on your device.
2. Upload index.html and any accompanying files to your hosting provider's website root/public folder.
3. Keep README.txt for reference; it does not need to be publicly served.
4. Open your hosted website and test customer and admin flows.

IMPORTANT LIMITATIONS
This is a browser-only prototype. It uses localStorage and client-side code, so accounts/content are not shared securely across users or devices. Credentials are embedded in the HTML and must not be considered secure. Payment proof and access controls are not production-secure. For a public production site, implement server-side authentication, a shared database, secure file storage, server-enforced per-item/folder permissions, and verified payment approval.

Changing the email or password inside this HTML is not secure authentication. Do not use real or sensitive passwords in a public prototype.

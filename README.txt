HOW TO UPLOAD TO GITHUB PAGES
1. Download and extract this ZIP.
2. Open your GitHub repository for the website.
3. Upload/replace index.html in the repository's published root folder.
4. Commit the change and wait for GitHub Pages to finish deploying.
5. Open the website and refresh it. If an old version remains, try a private browser tab or clear the cache.
6. README.txt is for your reference and is not required for the site to run.

IMPORTANT PROTOTYPE LIMITATIONS
This is a browser-only HTML/JavaScript prototype that stores data in localStorage.
- Customer accounts and content are not shared securely between different devices or visitors.
- Admin credentials are embedded in the HTML and can be viewed by anyone who inspects the source.
- Payment screenshots and access permissions are not protected by a server.
- Do not use real private credentials or rely on this version for real payments or sensitive content.

For a production website, implement server-side authentication, a shared database, secure file storage, server-enforced access permissions, and a verified payment approval process.

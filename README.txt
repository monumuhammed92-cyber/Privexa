Features:
- Customer registration and login.
- Each customer gets their own public page slug/link.
- Customer dashboard for content, folders, public page settings, and purchase history.
- Public published content is free to open.
- Public folders are free.
- Locked PDFs/items and locked folders have a payment screen.
- Payment screen shows admin-configured UPI ID and QR image.
- Buyer enters UPI transaction/reference ID and uploads screenshot proof.
- Admin approves/rejects payment requests.
- Approved access applies to the exact purchased item or folder only.
- Admin can publish content and folders, manage all content/folders, review customers, configure UPI and view their public admin page.

Important limitations:
This is a browser-only prototype using localStorage. It is not a secure production website, customer data does not sync between devices, and browser-side passwords/files are not protected adequately. Do not use for real payments or sensitive content. For a live multi-customer service, build a backend with secure authentication, a database, cloud file storage, and server-enforced folder/item permissions. Verify payment before granting access. These credentials are embedded in this browser-only prototype and are not secure for a live deployment.
